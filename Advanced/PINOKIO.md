## Why it exists (promo, one paragraph)

Pinokio is a free AI browser for Windows, macOS, and Linux. Click Discover,
install one small app, type a prompt, see an image or a short clip, delete it.
That is how a skeptic learns tokens, checkpoints, and node graphs without a
lecture. Comfy-style node canvases make the decision tree visible: encode →
sample → decode. Useful later for QSR / visual SOP work. Not a Kyocera tool.
Not on Greg's stick.

## Demo discipline (if someone installs it)

folder when you have them (`Advanced/pinokio-shots/` — add later).
