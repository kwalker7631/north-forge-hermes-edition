NORTH FORGE — ADMIN, FIRST TIME ON A NEW PC
You do not type git commands to build a stick after this page is done.

--------------------------------
ONCE on this computer (not every stick)
--------------------------------
1. Install Git for Windows. Next, Next, Finish.
   https://git-scm.com/download/win

2. Install GitHub CLI. Next, Next, Finish.
   https://cli.github.com/

3. Install Python 3.11 or newer if the box asks for it.
   https://www.python.org/downloads/
   Check the box "Add python.exe to PATH".

4. Open "GitHub CLI" or PowerShell ONE time and type only this:

     gh auth login

   Choose GitHub.com, HTTPS, Yes, Login with a web browser.
   That is the only command you ever type.

5. Get this console onto the PC (pick one):
   A. In the browser, open the private repo while signed in:
      https://github.com/kwalker7631/north-forge-hermes-edition
      Code → Download ZIP → unzip → open folder
      Advanced\deploy-console\
   B. Or, if the repo is already cloned, open that same folder.

--------------------------------
EVERY stick after that
--------------------------------
1. Plug in a blank USB, 8 GB or larger.
2. Right-click Launch-Deploy-Console.cmd
   → Run as administrator
3. A page opens. If it does not, look at the black window for the error.
4. Pick the USB.
5. Locked stick = teammate. Open stick = you.
6. What it opens as:
      North Forge / Kyocera     ← support team (priority)
      Pocket Penny              ← budget helper
      Pine Barron Farms         ← studio, still growing
      Field Service              ← technician/sales-rep voice overlay (4th
                                    edition; part of a Prime/BLACK-NORTH
                                    build, not part of the standard
                                    Excalibur curated set - see EXCALIBUR.md)
7. Type FORMAT
8. Type the admin passcode (one field in the console)
9. Click Format + deploy
10. Wait. First stick can take a long time. Leave it alone.
11. When it says DEPLOYMENT COMPLETE, do not eject yet.
12. Configure the inference provider — the drive cannot answer anything
    without this, and the console does not do it for you yet. Open
    PowerShell in the stick's checkout folder (<drive>\north-forge-agent)
    and type:

      $env:HERMES_HOME = "<drive>\north-forge-agent-data"
      hermes config set ANTHROPIC_API_KEY <the real key>
      hermes config set model anthropic/claude-sonnet-5

    Check it worked: hermes config show — Anthropic should show a masked
    key, Model should read anthropic/claude-sonnet-5. Then run a real
    test question with: hermes -z "..." — a real answer, not an error,
    means it's ready.
13. Eject the stick.

Hand the stick to the teammate with HOW_TO_START.txt
They double-click "Start North Forge". They never see this folder.

--------------------------------
What "sales" vs "full" means now
--------------------------------
The old runtime FULL / SALES toggle on the Kyocera drive (`toggle-mode.bat`)
was retired 2026-09-11. As of the 2026-09-14 four-drive-class redesign,
"Sales" is back, but as a build-time drive CLASS stamped by nf-setup.ps1 /
hermes_cli.nf_tier at provisioning, not a runtime toggle - see the deploy
console UI's own current description (Advanced/deploy-console/ui/index.html):
a Sales-class drive (label pattern <NameInitial>-NORSA) is fully functional
but deliberately narrow - sales-relevant skills only, zero service/
troubleshooting content, zero network/code-access tools. That is a different,
narrower thing than "Locked + Kyocera" below, which is still accurate for
the Tier full/basic (Open stick/Locked stick) distinction this section
otherwise describes:

  Locked stick  = one project only (safe for the team)
  Open stick    = you can switch projects (Kyocera, Penny, Pine Barron,
                  Field Service)

Kyocera content is one profile. There is not a separate "sales-only Kyocera"
skill pack yet. A sales-rep stick today is: Locked + Kyocera, or Locked +
field-service voice - or, if a true Sales-class drive-class build is wanted,
the newer drive-class mechanism above, not this toggle. Do not promise a
stripped sales edition until that profile exists.
