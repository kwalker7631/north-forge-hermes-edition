# Deploy a stick (admin)

Step-by-step with almost no typing: [ADMIN_FIRST_TIME.txt](ADMIN_FIRST_TIME.txt)

## Before you click Format

1. Right-click `Launch-Deploy-Console.cmd` → Run as administrator.
2. Pick the USB (8 GB or larger).
3. **Assigned to:** first and last name. Greg Warhol becomes volume label `Greg W-North`.
4. **Agent name:** leave blank for North Forge, or type a nickname.
5. Locked stick for a teammate. Kyocera unless you mean otherwise.
6. Type FORMAT. Type the admin passcode twice.
7. Wait. Hand them the stick and HOW_TO_START.txt.

Teammate steps: [FOR_THE_PERSON_GETTING_THIS_DRIVE.txt](FOR_THE_PERSON_GETTING_THIS_DRIVE.txt)
