# AI playground (future offering)

A downloadable Pinokio lab so someone can *see* models, images, and
short video without a lecture. Same idea as approachable tools (InVideo
and the like): one web page, add a thing, try it, remove it.

This is not the desk. North Forge answers the call. The playground is
how a skeptic learns what local generation looks like.

## How it can run

| Where | When |
|---|---|
| USB `pinokio-home` on BLACK-NORTH | Enough free space. One or two models only. |
| Separate large external | When the master stick is full. Retarget Pinokio Home. |
| Server / shared box | One strong GPU machine, many users hit the web UI. |
| User's own PC | Optional. Needs a serious GPU. Not the default. |

Local image/video at decent speed wants a real GPU and a fast disk.
A thumb drive on a dock laptop will install. It will not feel like a
studio PC. Say that in the offering or people will call it broken.
