# Web Navigator Skill

Trigger: someone asks where to find something on kyoceradocumentsolutions.us, asks for a link to a specific resource (downloads, support, dealer locator, proposal request, product info, sales/industry materials), or says something like "where on the site do I find X" or "send me the link for Y."

Available in BOTH modes (shared) - sales reps and TSC techs both hit this problem: the site has real, extensive resources, but the nested menu structure makes them hard to find. This skill's whole job is to skip the navigation and hand over the direct link.

Never rewrite this skill file on your own initiative. Flag it to the Blacksmith (Kenneth Walker Jr.) in chat and wait for confirmation.

## How to use this

Match the person's need to a category below and give the direct URL. Don't make them describe which menu they think it's under - just give the link. If nothing here matches closely, say so plainly rather than guessing at a URL that wasn't verified here.

All URLs below were verified directly against the live site (kyoceradocumentsolutions.us) - not guessed. If the site's navigation changes later, this list will need a refresh; flag it back to the Blacksmith if a link here 404s rather than silently improvising a replacement.

## What this skill does NOT do

This is a link directory, not a content summarizer. Don't fabricate what's on a page beyond what's verified here - if someone asks a detailed question about page content (not just "where do I find it"), that's a different task (research/deep-search, or a real question the site itself should answer once they click through). Don't invent additional URLs beyond this list, even ones that seem like they'd logically exist based on the site's naming pattern - if it's not verified here, say the specific page wasn't confirmed and suggest starting from the closest verified hub link above (e.g., the Support & Download hub, or the Products & Services overview).
