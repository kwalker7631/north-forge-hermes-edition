# /pinokio

North Forge is the desk. Pinokio is the lab on the **same drive**.

1. Double-click **Start Pinokio Lab** at the drive root.
2. Set Home to `pinokio-home` on this stick if asked. No spaces.
3. Install one Discover app. Learn. Close it. Return to North Forge.
